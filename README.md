# Projetos Python

## Sobre o projeto
Repositório com projetos e exercícios desenvolvidos durante meus estudos de Python. O principal projeto atual é um jogo de cartas 21 executado no terminal, usado para praticar lógica de programação e organização de código.

## Projeto em destaque — Jogo 21
Aplicação em terminal na qual dois jogadores recebem cartas, podem solicitar novas cartas e, ao final, os pontos são comparados.

## Conceitos praticados
- Variáveis e tipos de dados
- Listas
- Funções
- `if`, `elif` e `else`
- Laços `for` e `while`
- Entrada de dados com `input()`
- Formatação de saída
- Uso do módulo `random`
- Organização do código em funções

## Tecnologias
- Python

## Como executar
1. Tenha o Python instalado.
2. Clone o repositório.
3. Execute `Blackjack.py` pelo terminal.

Exemplo:
```bash
python Blackjack.py
```

## Aprendizados
O projeto foi usado para consolidar fundamentos de Python, decomposição do problema em funções e controle do fluxo do programa.
